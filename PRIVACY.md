# Publication and privacy boundaries

## What this repository contains

Only a curated concept overview, a high-level architecture description, a newly written synthetic example, and this publication policy. It is not a mirror of the development workspace.

## What is deliberately excluded

- Manuscripts, author story outlines, and real conversation transcripts.
- Source code, internal prompts, private implementation specifications, and deployment configuration.
- API keys, environment files, credentials, session tokens, and account information.
- Local databases, backups, exports, and machine-specific paths.
- Raw model requests/responses, private evaluation fixtures, budget ledgers, and operational logs.
- Screenshots that could reveal story material or personal details.

The implementation remains outside this public upload. This repository is not a private backup of the full application.

## Publication discipline

Future changes should be reviewed as a small explicit file list. Do not copy the entire project here or rely on ignore rules alone to prevent disclosure. Review prose as well as code: examples, filenames, screenshots, and logs can reveal private information without containing a credential.

Public copies can persist after removal. New material should therefore be reviewed before publication, not merely cleaned up afterward.

## Intended application safeguards

The design calls for preserving author provenance, keeping proposals separate from approvals, making external model processing explicit, bounding paid execution, and retaining recovery information. These are design commitments, not a guarantee that every implementation path is fully verified.

Do not submit confidential manuscripts, credentials, or personal information in public issues. This showcase is not a manuscript-submission service or a hosted writing application.
